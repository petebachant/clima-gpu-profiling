## Why the profiling stages live here

An experiment that reads `results/nsys/baseline.sqlite` does not own its inputs:
the next experiment overwrites that path, and the write-up silently restates
itself against a different run. Declaring the profiling stages in this file, with
output paths scoped to the experiment, means nothing is shared and nothing can be
clobbered. Freezing this file then freezes the whole experiment at once, because
`frozen` applies to every stage a Markdown file declares.

The profiles are large (about 930 MB per arm) and are a cache, not the record:
they can be regenerated by checking out this experiment's tag and running this
file, so they may be garbage-collected. The record is the statistics JSON below,
which is stored in Git and is a few kilobytes.
